# Requisitos Técnicos

## Descripción de la sección

Define las condiciones técnicas necesarias para ejecutar y desarrollar el videojuego.

## Requisitos mínimos

**Sistema operativo:** Windows 10 (64-bit) / macOS Ventura

**CPU:** Procesador Quad-Core a 2.5 GHz (Ej: Intel Core i5-7400 o AMD Ryzen 3 1200)

**GPU:** Tarjeta gráfica con soporte completo para URP y características modernas con 4 GB+ de VRAM (Ej: NVIDIA GeForce GTX 1660 Super o AMD Radeon RX 580)

**RAM:** 8 GB de memoria RAM

**Almacenamiento:**  2 GB de espacio disponible en unidad NVMe SSD

**Resolución:** 1280 × 720 (720p) 

**Conexión:** No requerida (Modo un jugador offline)

## Requisitos recomendados

**Sistema operativo:** Windows 11 (64-bit) / macOS Sonoma o superior

**CPU:** Procesador Hexa-Core o superior a 3.0 GHz (Ej: Intel Core i5-12400 o AMD Ryzen 5 5600X)

**GPU:** Tarjeta gráfica con soporte completo para URP y características modernas con 4 GB+ de VRAM (Ej: NVIDIA GeForce GTX 1660 Super o AMD Radeon RX 580)

**RAM:** 16 GB de memoria RAM DDR4 / DDR5

**Almacenamiento:** 2 GB de espacio disponible en unidad NVMe SSD
